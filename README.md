# WhatImWatching

Сайт, на котором можно вспомнить всё просмотренное аниме, поставить оценки и получить рекомендации по своему вкусу.
Работает целиком в браузере: без сервера, без регистрации, без ключей API.

## Файлы

| Файл | Что делает |
|---|---|
| `index.html` | разметка страницы |
| `style.css` | оформление (светлая и тёмная тема) |
| `app.js` | вся логика: подключение к базам, каталог, список, поиск, рекомендации, экспорт/импорт |

## Откуда данные

При запуске сайт по очереди пробует три источника и берёт первый, который ответил за 8 секунд:

1. **Shikimori** — русские названия, описания и жанры. Перебираются домены `shikimori.io`, `shikimori.one`, `shikimori.me`.
2. **AniList** — если Shikimori недоступен. Названия и описания на английском.
3. **Jikan (MyAnimeList)** — запасной вариант.

Удачный источник запоминается и в следующий раз пробуется первым. Какой источник сейчас используется, написано под заголовком сайта.
Если не ответил ни один, сайт показывает ошибку и список того, что именно не сработало.

Все тайтлы хранятся по id MyAnimeList (у Shikimori он тот же, у AniList есть поле `idMal`), поэтому список не ломается при смене источника.
Ответы кэшируются в браузере: каталог на 3 дня, описания и «похожие» на 7 дней.

## Как устроены рекомендации

1. Берутся до 18 тайтлов, которые ты оценил на 7 и выше (тайтлы без оценки — с маленьким весом).
2. Для каждого загружается список «похожих» из выбранного источника.
3. Каждому кандидату начисляются очки: `вес оценки × log2(1 + сила связи)`. Вес: 7 → 0.5, 8 → 1, 9 → 1.5, 10 → 2. Тайтлы с оценкой 4 и ниже вычитают очки у своих «похожих».
4. Кандидаты, которых советуют сразу несколько любимых тайтлов, получают бонус.
5. Просмотренное, отложенное, «не помню» и «не интересно» исключаются.

Если оценок ещё нет, показываются самые высоко оценённые тайтлы.

## Где хранится список

В `localStorage` браузера. Он не уходит ни на какой сервер, но и не синхронизируется между устройствами.
Во вкладке «Мой список» есть блок «Сохранить или перенести список»: там можно скачать файл и загрузить его на другом устройстве.

## Как проверить у себя

Открой `index.html` двойным кликом. Нужен интернет.

## Как выложить в интернет (GitHub Pages)

1. Создай на GitHub новый публичный репозиторий, например `whatimwatching`.
2. Загрузи в него три файла: `index.html`, `style.css`, `app.js` (кнопка **Add file → Upload files**).
3. Открой **Settings → Pages**, в разделе **Branch** выбери `main` и папку `/ (root)`, нажми **Save**.
4. Через минуту сайт будет доступен по адресу `https://<твой-логин>.github.io/whatimwatching/`.

Альтернатива без Git: перетащи папку на [app.netlify.com/drop](https://app.netlify.com/drop).
